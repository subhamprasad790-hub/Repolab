# MAMBO-8: Toast shows incorrect message

**Summary:** A toast notification displays an incorrect message.

## Steps to reproduce
1. Perform the action that triggers a toast notification.
2. Observe the message shown in the toast.

## Expected
The toast shows the message matching the action performed.

## Actual
The toast shows an incorrect/mismatched message.

## Severity
Low - UX/messaging issue.
